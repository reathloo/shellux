# Security

Security updates are provided for the latest Shellux release.

Please report suspected vulnerabilities through
[GitHub's private vulnerability reporting](https://github.com/reathloo/shellux/security/advisories/new).
Do not include sensitive details in a public issue.

Include the Shellux version, operating system, affected command or theme, and a
minimal reproduction when possible. Reports about third-party theme artwork or
licensing can use a normal issue as long as they contain no sensitive data.
